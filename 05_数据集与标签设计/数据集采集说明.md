# 数据集采集说明（光稳智检 · 标签质检）

> 目标：采出一批**光照条件完全一致**的标签照片，用于训练/验证"正常 vs 缺陷"检测模型。
> 数据集环境必须**就是要演示的那套环境**。

---

## 一、要准备的材料

| 类别 | 具体物品 | 数量 | 说明 |
|---|---|---|---|
| 纸张 | A4 普通打印纸 70~80g | 10~15 张 | 不要用厚卡纸（反光与厚度都会变） |
| 打印 | 打印机（激光/喷墨均可） | — | ★ 同一批数据用同一台打印机，保证打印质感一致 |
| 标签 | `print/A4_*.png`（本目录） | 6 张 | 每个变体打一张（每张 18 个标签） |
| 裁切 | 剪刀/美工刀 + 直尺 | 1 | 沿标签边线裁开 |
| 定位 | 硬纸板 + 胶带 | 若干 | 在箱底做"标签放置位"标记，保证每张放同一位置 |
| 载体 | 一张 A4 白纸 | 1 | 铺在箱底当固定载体（标签放在它上面） |
| 记录 | 记号笔 | 1 | 在标签**背面**写编号（正面不能写） |
| 工具 | ESP32 + 5V 电源 + USB 摄像头 | 各 1 | 全部接好并保持不动 |
| 固件 | **必须烧 `01_ESP32固件/lightguard_esp32.ino`（正式固件）** | 1 块板 | 采集脚本与网页都依赖正式固件的 JSON 协议（`STATUS` / `LIGHT n` / `RESULT`）。验证固件（`light_pwm_test` 等）用的是另一套文本协议，采集会失败 |
| 软件 | `ffmpeg`（方式 C 抓帧用） | — | 方式 A / B 都不需要；方式 C 找不到 ffmpeg 会直接退出 |
| 软件 | Node.js（方式 B 用） | — | 方式 A（独立采集台）不需要 Node |
| 软件 | Python 3（方式 A 用） | — | `py -3.11`；需要 `flask`、`pyserial`（`console\README_独立采集台.md` 里有安装命令） |

**标签设计**：60 × 40 mm，含外框、标题、型号/批次文字、6×6 方块阵列、条码、编号。
每个 A4 页排 **18 个**，页脚有一条 **100 mm 校验尺**。

## 二、六个标签变体（类别名 = 文件名 = 采集时的 `-Class` 参数）

| 类别 | 缺陷 | 图上表现 | 缺陷强度（与正常图案的差异像素） |
|---|---|---|---|
| `normal` | 无 | 边框完整、文字/条码清晰 | — |
| `brokenline` | 断线 | **外框上边缺一段（14mm）** | 830 px（0.25%）—— 一眼可见 |
| `faint` | 缺墨 | **条码右半段变浅灰** | 13,272 px（3.97%）—— 明显 |
| `stain` | 污点 | **黑色斑块（5×3.2mm）盖住型号文字** | 1,791 px（0.54%）—— 一眼可见 |
| `scratch` | 划痕 | **白色划痕（0.9mm 宽）斜穿条码** | 1,062 px（0.32%）—— 肉眼可见 |
| `offset` | 偏位重影 | **整体重印偏移 0.7mm，文字发虚** | 82,788 px（24.74%）—— 非常明显 |

> 说明：**像素占比小 ≠ 看不见**。`brokenline` 只改了 0.25% 的像素，但那是"边框断一大截"，
> 人一眼就能看出来；反过来，细线划痕占比虽不低，但因为它又细又局部，才需要加粗到 0.9mm。
> 上面每一类的可见性都在生成后用**逐像素差异 + 目视**双重确认过。

> 以后要加新缺陷类型：改 `make_labels.ps1` 里的 `$kinds` 和 `New-Label` 的 switch 分支，
> 重新运行即可（会自动重新生成标签和 A4 打印页）。

## 三、打印

**推荐直接用 PDF 打**（本目录 `print/` 里已生成好，页面尺寸钉死为 A4，不会被缩放）：

| 文件 | 说明 |
|---|---|
| `print/标签打印_全6页_A4.pdf` | 6 页合并版，一次打完 6 类 |
| `print/标签打印_1_正常_normal.pdf` … `_6_偏位重影_offset.pdf` | 每类单页（本地生成，适合先试打一张） |
| 生成脚本 `make_print_pdf.py` | 单页 PDF 不在提交包里，需要时跑一次即可重新生成 |

步骤：

1. 打开 `print/标签打印_全6页_A4.pdf`，打印设置：**A4、单面、缩放"实际大小 / 100%"**（⚠️ 不要选"适应页面/缩放"）
2. 打完后**用页脚校验尺量一下**：应该是 **100 mm**（生成侧实测 100.41 mm）。不对就是缩放选错了，重新打
3. 确认无误后，把其余页也打出来
4. 沿标签边线裁开（裁切标记在四角）

> 也可以直接打 `print/A4_*.png`（内容与 PDF 相同，都是 A4@300dpi / 2480×3508），
> 但某些看图软件会默认缩放，所以**优先用 PDF**。
> 数量建议：正常样本 40 张 → 打 3 页；5 类缺陷各 20 张 → 每类 2 页；合计约 13 页。

## 四、采集前必须固定的事（否则数据白采）

| 项 | 要求 |
|---|---|
| 光照 | 固定亮度（推荐 **25%**）；**不要用自动闭环**；PWM 固定 **8 kHz**。按实测增益 28.5 lx/% 换算，25% 对应约 760 lx（含约 46 lx 环境光底数），不是 300~500 lx；**该换算只对 28.5 lx/% 那一 BH1750 摆放位置成立**（不同位置实测出现过 39 lx/%），采集前请按最终箱内位置实测一遍亮度↔照度对照 |
| 箱盖 | 全程关闭，状态一致 |
| 相机 | 位置固定、**对焦锁死**（调好后别碰）、分辨率一致 |
| 标签位置 | 每张都放在箱底同一个标记位上 |
| 曝光 | 尽量锁定；锁不了就靠固定光照让自动曝光稳定 |
| 亮度别动 | 采集过程中不要把 `LIGHT` 值改来改去 |

## 五、采集流程

有四种方式，**推荐方式 A（独立采集台）**，因为它最省事：双击一下就有页面，
照度直接由程序从串口读、当场写进记录表，不依赖浏览器专属接口。

---

### 方式 A：独立采集台（推荐）

**双击 `console\0_启动采集台.bat`** → 浏览器自动打开 `http://127.0.0.1:8789/`

这是**自带页面的独立小工具**（就在 `console\` 目录里），不需要 Node，不依赖任何已有软件，
只要有 Python + 摄像头就能跑，拷到别的电脑也一样用。

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① | 点 **打开摄像头** | 相机不对就在下拉框里换一个 |
| ② | 点 **设为该亮度**（默认 25%） | 等右侧"照度稳定"显示 **稳定** 再开始 |
| ③ | 点右侧 **类别** 切换 | 正常 / 断线 / 缺墨 / 污点 / 划痕 / 偏位重影 |
| ④ | 放好标签 → 按 **Enter**（或点 📷 采集一张） | 图片落盘 + 记录表加一行 + 缩略图出现 |
| ⑤ | 采错按 **Z** 撤销；采完点 **导出数据集 zip** | 撤销会把图片和记录表那一行一起删掉 |

- 快捷键：`Enter` 采集 · `Z` 撤销 · `0` 关灯
- ★ **必须用 `127.0.0.1` 打开**，用局域网 IP 打开时浏览器会拒绝摄像头权限
- **还没接 ESP32 也能先练手**：双击 `console\0_启动采集台_不接硬件.bat`（照度记空，其余照常）
- 连上串口时和退出时都会自动发 `LIGHT 0` 关灯
- 记录表里的照度/亮度是**服务端现读的硬件真实值**，前端传不了假数据
- 详细说明见 `console\README_独立采集台.md`

---

### 方式 B：网页采集台（Node 版，不想用 Python 时选它）

**双击 `7_网页采集.bat`** → 会自动起本地服务并打开 Chrome。

页面地址：`http://127.0.0.1:8788/`

页面上按顺序做三件事（每件都变成一个绿点）：

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① | 点 **连接 ESP32 串口** | 浏览器弹出串口列表 → 选 **COM5** |
| ① | 点 **打开摄像头** | 浏览器请求摄像头权限 → 允许；下拉框里选 **USB Camera** |
| ① | 点 **选择保存目录** | 选 **dataset** 文件夹（照片会写进它下面的 `images\<类别>\`） |
| ② | 亮度填 **25** → 点 **应用** | 页面会显示实时照度和"是否稳定" |
| ③ | 点类别（正常 / 断线 / 缺墨 / 污点 / 划痕 / 重影） | 决定照片存到哪个子目录 |
| ④ | 放好标签 → **按回车**（或点大按钮） | 自动等照度稳定 → 抓帧 → 保存 → 计数 +1 |

**网页版额外的好处**：

- **实时预览**：拍之前先看画面 —— 标签是否完整、居中、字清楚、有没有过曝
- **照度实时显示 + 稳定性判断**：数字变绿（● 稳定）才拍，避免"照片亮度忽高忽低"
- **最近 8 张缩略图**：能立刻发现自己拍歪了/拍暗了
- **自动记录 CSV**：每张的照度、亮度、时间都写进 `采集记录表.csv`（带 BOM，Excel 直接打开）
- 序号自动接着已有的往下排（可以在同一类别上分几次采）

**支持的浏览器**：Chrome / Edge（用了 Web Serial 和目录写入 API）。
绿色 Chrome 图标已确认安装。

**停止**：直接关掉标签页；再关掉那个最小化的"LightGuard Capture Server"黑窗口。

### 方式 C：双击批处理（黑窗口，只需按回车）

不想用浏览器时可用。本目录下有 8 个 `.bat`，**双击就能用**：

| 双击这个文件 | 作用 |
|---|---|
| `0_自检.bat` | 自检（串口 + 亮度 + 摄像头），**采集前先跑这个** |
| `1_采集_正常_normal.bat` | 采正常样本 40 张 |
| `2_采集_断线_brokenline.bat` | 采断线缺陷 20 张 |
| `3_采集_缺墨_faint.bat` | 采缺墨缺陷 20 张 |
| `4_采集_污点_stain.bat` | 采污点缺陷 20 张 |
| `5_采集_划痕_scratch.bat` | 采划痕缺陷 20 张 |
| `6_采集_重影_offset.bat` | 采偏位重影缺陷 20 张 |
| `7_网页采集.bat` | 打开方式 B 的网页采集台（Node 版） |
| `console\0_启动采集台.bat` | 打开方式 A 的独立采集台（推荐） |

**双击后会发生什么**：

```
① 弹出一个黑窗口（命令行窗口），显示自检/采集信息
② 出现提示：[1/40] 放入第 1 个样品（normal），放好后按回车…
③ 你把标签放进箱子里 → 【按一下回车键】← 全程只需要按这一个键
④ 窗口显示：  OK  normal_0001.jpg   (410.8 lx)
⑤ 自动提示第 2 个…… 重复 ③④
⑥ 全部采完显示汇总，窗口提示"按任意键关闭"
```

**注意**：
- 采集时**不要**打开 Windows"相机"应用、微信视频、腾讯会议等占用摄像头的程序
- 中途想停止：**直接关掉那个黑窗口**即可（灯带可能还亮着 —— 再双击 `0_自检.bat`，或直接拔 5V）
- 每个窗口里显示的 `(xxx lx)` 就是这一张的照度，可以用来核对光照是否一致

### 方式 D：手工敲命令（需要改数量或类别时用）

```powershell
cd D:\codex\lightguard-hardware-demo\dataset

# 0) 先自检（串口 + 亮度 + 摄像头是否都正常）
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -DryRun

# 1) 采正常样本 20 张
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class normal -Count 20

# 2) 依次采各缺陷类型
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class brokenline -Count 15
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class faint      -Count 15
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class stain      -Count 15
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class scratch    -Count 15
powershell -ExecutionPolicy Bypass -File .\capture_dataset.ps1 -Class offset     -Count 15
```

脚本每张的流程：**提示→你放好标签→按回车→自动抓帧并记录照度**。

- 图片保存到 `images\<类别>\<类别>_0001.jpg`
- 同时把 `文件名, 类别, 缺陷类型, 照度lx, 亮度%, 时间` 追加写进 `采集记录表.csv`
  （UTF-8 带 BOM，Excel 直接双击打开中文不乱码；`normal` 的"缺陷类型"写"无"）
- 每张图都带照度记录，便于事后核对"这一批数据是不是同一光照条件"
- 结束时自动把灯带关到 0%

**参数说明**：

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Class` | 必填 | 类别名（见上表六个） |
| `-Count` | 10 | 本次采多少张 |
| `-Brightness` | 25 | 固定亮度（%） |
| `-Shots` | 1 | 每个样品拍几张（多拍便于挑选） |
| `-Camera` | `USB Camera` | 摄像头设备名 |
| `-NoEsp` | — | 不连 ESP32（只测摄像头通路时用） |
| `-DryRun` | — | 只自检不采集 |

## 六、数量与划分建议

| 类别 | 建议数量 |
|---|---|
| normal | 60~100 |
| 每类缺陷 | 30~50（至少 3~5 类） |

**划分**：采集端按"类别"存图，训练脚本按**固定的 5 个目录**读图，两者之间必须做一次划分映射：

| 采集到的目录 | 划分到训练脚本的目录 | 说明 |
|---|---|---|
| `images\normal\` | `train/good` + `calibration/good` + `test/good` | 约 6 : 2 : 2；三份必须来自**不同样品** |
| `images\brokenline\` `faint\` `stain\` `scratch\` `offset\` | `calibration/defect` + `test/defect` | 约 1 : 2；**缺陷图绝不能进 `train/good`** |

> ★ **两条硬规则**
> 1. **按"样品"划分，不能按图片划分** —— 同一张标签的多张照片不能一半进训练、一半进测试，否则数据泄漏、测试准确率虚高；
> 2. **缺陷图片不能进入 `train/good`** —— 训练只用正常图建记忆库，缺陷图只用于校准阈值和最终测试（见软件包 `自定义标签模型训练说明.md`）。
>
> 训练脚本本身不做自动划分，需要手工或脚本完成。可参照下面这段 PowerShell（`$src`/`$dst` 改成实际路径）：

```powershell
$src = "<采集根目录>\images"
$dst = "<01_可运行系统>\datasets\printed_label"
foreach ($d in "train\good","calibration\good","calibration\defect","test\good","test\defect") {
    New-Item -ItemType Directory -Force -Path (Join-Path $dst $d) | Out-Null
}
$normal = Get-ChildItem (Join-Path $src "normal") -File | Sort-Object Name
$n = $normal.Count
$normal[0..[int]($n*0.6-1)]             | Copy-Item -Destination (Join-Path $dst "train\good")
$normal[[int]($n*0.6)..[int]($n*0.8-1)] | Copy-Item -Destination (Join-Path $dst "calibration\good")
$normal[[int]($n*0.8)..($n-1)]          | Copy-Item -Destination (Join-Path $dst "test\good")
$defects = Get-ChildItem $src -Directory | Where-Object { $_.Name -ne "normal" } |
           ForEach-Object { Get-ChildItem $_.FullName -File } | Sort-Object Name
$m = $defects.Count
$defects[0..[int]($m/3-1)]              | Copy-Item -Destination (Join-Path $dst "calibration\defect")
$defects[[int]($m/3)..($m-1)]           | Copy-Item -Destination (Join-Path $dst "test\defect")
Write-Host "划分完成：请到 $dst 下核对 5 个目录的数量"
```

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 打印出来标签尺寸不对 | 打印缩放没选"实际大小"；用页脚 100 mm 校验尺确认 |
| 画面一片白 | 照度太高（实测 100% 会过曝）；降到 20~35% |
| 画面偏暗、噪点多 | 照度太低；在推荐区间内往上调到 30~35%，或检查标签是否被遮挡、箱盖是否关好 |
| 画面有横向条纹 | PWM 频率不对（应为 8 kHz）；确认烧的是最新固件 |
| 脚本报"打不开串口 COM5" | ESP32 没插好或端口号变了；用 `-NoEsp` 可先跳过 |
| 脚本报"找不到摄像头" | 摄像头 USB 没插好；或设备名不是 `USB Camera`（用提示里的名字传给 `-Camera`） |
| 想中途停止 | 直接关掉窗口即可（灯带可能还亮着，用 Arduino 串口监视器发 `LIGHT 0`） |
