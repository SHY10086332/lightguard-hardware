# 数据集采集台（独立版）

一个**自带页面的小工具**，专门用来采样本、记照度、导出数据集。

它**不修改、也不依赖任何已有软件**：只要电脑上有 Python 3 和摄像头就能跑，
拷到别的电脑也一样用。与硬件之间只通过我们自己的固件串口协议对话。

---

## 一、怎么启动

### 先确认依赖（只做一次）

```powershell
py -3.11 -m pip install flask pyserial
```

`flask` = 提供页面和接口；`pyserial` = 读 ESP32 串口（没装的话工具仍能启动，只是照度读不到）。
本机已确认可用版本：Python 3.11.9 + flask 3.1.3 + pyserial 3.5。

### 再启动

| 情况 | 怎么做 |
|---|---|
| 接了 ESP32 | 双击 `0_启动采集台.bat` |
| **还没接 ESP32**（可以先练手） | 双击 `0_启动采集台_不接硬件.bat`（照度记空，其余照常） |
| 命令行 | `py -3.11 dataset_console.py`（加 `--no-serial` 表示不连硬件） |

启动后浏览器会自动打开 **http://127.0.0.1:8789/**。

> ⚠️ **必须用 `127.0.0.1` 打开**。浏览器的摄像头权限只在"安全上下文"里给，
> `http://127.0.0.1` 和 `http://localhost` 算安全上下文，用局域网 IP（`http://192.168.x.x:8789`）
> 打开时浏览器会**直接拒绝**摄像头。

## 二、页面怎么用

1. 点 **打开摄像头** → 画面出现在左边（相机选错了就在下拉框里换一个）。
2. 点 **设为该亮度**（默认 25%）→ 灯带亮到固定亮度；右侧"照度稳定"显示 **稳定** 再开始采。
   ⚠️ **等 10~15 秒再拍第一张**：改亮度后相机的自动曝光要十几秒才收敛（实测从全白到正常要 5 帧）。
3. 勾上 **一图一标签（自动裁切）**（默认已勾）——见下方第三节。
4. 点右边 **类别**（正常 / 断线 / 缺墨 / 污点 / 划痕 / 偏位重影）切换当前类别。
5. 点 **📷 采集一张**（或按 `Enter`）→ 自动裁出画面里**所有完整标签**、逐个存成一张图 + 每个标签一行记录。
6. 采错了点 **↶ 撤销上一张**（或按 `Z`）→ 删掉该类最新一张及其记录行（一图一标签模式下要连按几次）。
7. 采完点 **导出数据集 zip** → 打包下载，交给训练脚本。

快捷键：`Enter` 采集一张 · `Z` 撤销上一张 · `0` 关灯。

## 三、一图一标签（自动裁切）——推荐

相机一帧里能看到十来个标签，**数据集需要的是"一张图一个标签"**，所以采集台会现场裁：

| 步骤 | 说明 |
|---|---|
| ① 找标签 | 按"60×40mm → 长宽比 1.5"这个先验找矩形（比"找最大暗块"可靠；后者实测会把桌面暗区误认成标签） |
| ② 只留完整的 | **碰到画面边缘的一律剔除**（半个标签对训练没用）——按"哪列完整就保留"的规则 |
| ③ 去重排序 | 标签内部的条码/文字会产生一堆小轮廓，按位置合并；再从上到下、从左到右编号 |
| ④ 裁切留边 | 向外留 3% 边距，避免切到外框 |
| ⑤ 记账 | **每个标签单独一行**写进 `采集记录表.csv`（文件名/类别/照度/亮度/时间） |
| ⑥ 现场复核 | 页面显示**裁切预览图**：<b>绿框=已保存</b>、<b>红框=被裁掉已剔除</b>，并提示剔除了几个 |

**实测（2026-10-09，真实相机帧）**：一帧里保存 6 个、剔除 3 个（最下行被画面下边缘切掉），
裁出来的图 469~484 × 303~320 px、长宽比 1.5，每张都是一个完整标签。

**裁切模块可单独自测**（合成图，不需要硬件）：

```powershell
py -3.11 test_label_crop.py      # 11 项：完整纸 12 个全留、超出画面的 4 个剔除、空白纸不误检…
```

**想要"整帧一图"**（一图多标签）：把那个勾去掉即可，行为与以前一样。

### 安全约定（重要）

- 工具**连上串口时**和**退出时**都会自动发 `LIGHT 0` 关灯；
- 正式固件默认亮度已是 **0%**（复位不会亮）；仍建议拔插 USB 或按复位前，
  建议先点「关灯」，或者干脆把灯带的 5V 电源拔掉。

## 三、文件存到哪里

默认存在本目录下的 `dataset\`：

```
dataset\
├── images\
│   ├── normal\      normal_0001.jpg  normal_0002.jpg …
│   ├── brokenline\  …
│   └── …（共 6 类）
└── 采集记录表.csv    文件名,类别,缺陷类型,照度lx,亮度%,时间
```

要换目录：`py -3.11 dataset_console.py --out D:\data\mydataset`。

记录表里的 **照度 / 亮度是服务端从硬件读到的真实值**（页面每次采集时会现读一次），
前端传不了假数据，所以这份记录可以直接当采集证据用。

## 四、与硬件的接口（就是自己固件的协议）

`lightguard_esp32.ino` / 验证固件都实现了这套协议，115200 波特率，一行一条 JSON：

| 命令 | 回复 |
|---|---|
| `STATUS` | `{"ok":true,"lux":123.4,"brightness":25,"result":"idle"}` |
| `LIGHT <0-100>` | 设置亮度，并回一条 `STATUS` |
| `PING` | `{"ok":true,"device":"LIGHTGUARD_ESP32"}` |

串口默认**自动查找**（优先 CP2102 芯片：VID 10C4 / PID EA60）。
要指定就加 `--port COM5`。

## 五、常用参数

```powershell
py -3.11 dataset_console.py --no-serial              # 不接硬件
py -3.11 dataset_console.py --port COM5               # 指定串口
py -3.11 dataset_console.py --http-port 8790          # 换端口（默认 8789）
py -3.11 dataset_console.py --out D:\data\ds01        # 换数据集目录
py -3.11 dataset_console.py --no-browser              # 不自动开浏览器
```

## 六、采集纪律（决定模型准不准，比工具本身重要）

1. **同一套光照**：固定亮度（建议 25%）、盖上箱盖、灯带 PWM 必须是 **8 kHz** 那一版固件
   （1 kHz 会让相机画面出现横向频闪条纹，实测标准差 8.8）；
2. **固定机位**：相机、标签、灯带的相对位置全程不动，焦距锁定；
3. **照度要稳**：右侧显示"稳定"（最近 5 次波动 ≤15 lx）再按快门；
4. **别过曝**：100% 亮度纸面一片白、文字被冲掉，工作区间取 **20%~35%**；
5. **划分按样本不按图片**：同一张标签的多张照片只能进同一个集合（train / val / test），
   否则准确率会虚高。
