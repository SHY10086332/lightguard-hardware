# 数据集说明书（光稳智检 · 标签质检数据集）

> 用途：为"正常 vs 缺陷"异常检测提供**自采**训练/校准/测试数据。
> 本说明书同时是**采集与整理规范**：口径与 `AIC口径唯一基准.md` 第六节一致，逐条可核。
>
> 数据来源：**全部自采**（自研标签图案 + 自研采集台 + 自有硬件），不含任何第三方数据集素材。

---

## 一、一句话说明

用**自研生成的 6 类标签图案**打印在 A4 纸上，在**固定的光照与机位**下用 USB 摄像头采集，
由自研采集台**自动把每个完整标签裁成单张图片**，并把当时的照度、亮度、时间逐张记入记录表；
再按赛事要求划分成 `train/good`、`calibration/good`、`test/good`、`calibration/defect`、`test/defect`。

---

## 二、标签设计（可打印复现）

| 项 | 规格 |
|---|---|
| 单张标签尺寸 | **60 mm × 40 mm** |
| A4 每页数量 | **18 个**（3 列 × 6 行） |
| 页脚校验 | **100 mm 校验尺**（打印后用它确认没有被缩放；生成侧实测 100.41 mm） |
| 标签内容 | 标题、型号 `LG-2026-01`、批次、六×六方块阵列、条码、编号、`100% 全检` 字样、外框 |
| 打印要求 | A4、单面、**缩放"实际大小 / 100%"**；同一批数据用同一台打印机 |
| 生成脚本 | `make_labels.ps1`（图案）→ `make_print_pdf.py`（打印 PDF） |
| 打印文件 | `print/标签打印_全6页_A4.pdf`（6 页合并版） |

**6 类图案**（脚本生成时即注入差异，保证"人眼可见"）：

| 类别 | 中文 | 差异注入方式 |
|---|---|---|
| `normal` | 正常（合格品） | 无 |
| `brokenline` | 断线 | 方块阵列中缺一段 |
| `faint` | 缺墨 | 整体墨色变淡 |
| `stain` | 污点 | 叠加一处深色斑点 |
| `scratch` | 划痕 | 叠加一条 0.9 mm 宽刮痕（0.5 mm 太细，人眼难辨，已加粗） |
| `offset` | 偏位重影 | 局部图案整体位移 |

## 三、采集条件（必须与验收、演示**完全一致**）

| 项 | 要求 | 实测依据 |
|---|---|---|
| 固件 | **正式固件** `lightguard_esp32.ino`（验证固件协议不同，采集会失败） | 采集台按 `STATUS`/`LIGHT` 协议通信 |
| PWM | **8 kHz** | 1 kHz 时相机画面有频闪条纹（行 σ 8.85），8 kHz 后 **σ 0.50** |
| 亮度 | **25%**（工作区间 **20%~30%**） | 纸面亮度 215、对比度 170、过曝像素 0.00% |
| 等待 | 改亮度后**等 10~15 秒**再拍 | 相机自动曝光从全白收敛到正常需 5 帧（约 12 秒） |
| 机位 | 相机固定、**对焦锁死**、纸每次放回同一位置（贴角标） | 位置变化会让参考图比对误判 |
| 光照 | **全程不变**（同一亮度、同一 PWM、箱盖/环境光不变） | 验收光照 = 采集光照 = 演示光照 |
| 裁剪 | 一图一标签，**只保留完整标签**，被画面边缘裁掉的一律剔除 | 实测一帧：保存 6 个、剔除 3 个 |
| 列筛选 | 可只保留指定列（不同列亮度差可达 40 灰阶） | 实测 第1列 138.8 / 第2列 163.0 / 第3列 181.9 |

> ⚠️ 硬件侧还有一个待办：把 BH1750 固定到**箱内最终标签位**后重新标定
> （当前桌面几何实测 **9.77 lx/每1%**，达 900 lx 需 94% 亮度 → 与相机不过曝冲突，需按最终位置复标）。

## 四、目录与命名规范

```
dataset\
├── images\
│   ├── normal\      normal_0001.jpg  normal_0002.jpg  …
│   ├── brokenline\  brokenline_0001.jpg  …
│   ├── faint\  stain\  scratch\  offset\        ← 共 6 类
└── 采集记录表.csv
```

`采集记录表.csv` 字段（UTF-8 带 BOM，Excel 直接打开中文不乱码）：

| 字段 | 说明 |
|---|---|
| 文件名 | `<类别>_<四位序号>.jpg` |
| 类别 | 英文 key（与目录名一致） |
| 缺陷类型 | 中文（`正常` 记「无」） |
| **照度 lx** | **服务端从串口现读的硬件真值**（前端传不了假数据） |
| **亮度 %** | 同上 |
| 时间 | `YYYY-MM-DD HH:MM:SS`（**同一秒采集的多张 = 同一张纸 = 同一个样品**） |

## 五、划分规则（赛事硬要求，逐条落实）

| 要求 | 本数据集的做法 |
|---|---|
| 训练目录映射 | `images\normal\` → `train/good` + `calibration/good` + `test/good`（**≈6:2:2**）<br>5 类缺陷 → `calibration/defect` + `test/defect`（**≈1:2**） |
| **硬规则①：按"样品"划分，不能按图片划分** | 采集台一次按快门得到的多张图来自**同一张纸**，在记录表里**时间戳完全相同**；划分脚本**按时间戳分组**、整组分配，绝不拆散 |
| **硬规则②：缺陷图绝不能进 `train/good`** | 划分脚本只把 `normal` 送进 `train/*`，并对结果做断言检查 |

**划分工具**：`split_dataset.py`

```powershell
py -3.11 split_dataset.py --src <数据集目录>              # 输出到 <数据集目录>\..\split
py -3.11 split_dataset.py --src <数据集目录> --dry-run     # 只看怎么分，不写文件
```

输出：`train/good`、`calibration/good`、`test/good`、`calibration/defect`、`test/defect`、
`划分清单.csv`（每张图去了哪里 + 样品组号）、`数据集统计报告.md`（数量/照度统计 + 合规自检）。

**自测（合成数据，160 张 / 55 个样品组）实测输出**：

| 目标目录 | 张数 | 目标比例 | 结果 |
|---|---|---|---|
| `train/good` | 36 | 60% | ✓ 6:2:2 |
| `calibration/good` | 12 | 20% | ✓ |
| `test/good` | 12 | 20% | ✓ |
| `calibration/defect` | 34 | 33% | ✓ ≈1:2 |
| `test/defect` | 66 | 67% | ✓ |

合规自检输出：`[OK] train/good 只含合格品`、`[OK] 样品组没有被拆散`。

## 六、采集数量建议

| 类别 | 建议张数 | 对应打印页数 |
|---|---|---|
| normal（合格品） | **40~60** | 3 页（54 个标签，一图一标签模式下一次可采多个） |
| 5 类缺陷 各 | **20** | 每类 2 页 |
| 合计 | **约 140~160** | 约 13 页 |

## 七、质量检查（采完逐条过）

- [ ] 打印后**用尺子量页脚校验尺 = 100 mm**（不是 100 mm 就重新打印）
- [ ] 记录表里**照度数值集中**（同一亮度下应基本一致；出现明显离群说明光照被扰动过）
- [ ] 采集时看**裁切预览图**：绿框=已保存、红框=被剔除，确认没有半张标签被存进来
- [ ] 类别目录数量与预期一致（`images\<类别>\` 下的张数）
- [ ] 跑一次 `split_dataset.py --dry-run`，确认两条硬规则的 `[OK]` 都出现
- [ ] 抽 5 张图目视确认：**一张图只有一个完整标签**、字迹清晰、不过曝、无频闪条纹

## 八、已知局限（如实写明，不夸大）

1. **横向光照不均**：当前几何下纸面左侧比右侧暗约 40 灰阶（外侧 1/3 相差 45）。
   → 已通过"整张纸固定不动、只换纸"来保证一致性；也可用采集台的**列筛选**规避。
2. **样本量有限**：单次采集约 150 张，属于**演示与小规模验证**规模，不是产线级数据集。
3. **二维平面、单一视角**：仅覆盖"从上往下拍平铺标签"这一场景。
4. **未做旋转矫正**：标签轻微倾斜（>10°）时包围盒会偏大，采集时应把纸摆正。
5. **照度换算依赖摆放位置**：`lx/每1%` 随传感器与灯带距离变化（历史实测 8.65 / 9.77 / 28.5 / 39），
   引用时必须带位置前提。

## 九、素材许可与署名

- 标签图案由本项目**自行生成**（`make_labels.ps1`），**不含任何第三方数据集或素材**，
  无需外部许可与署名；
- 图片由本项目**自行采集**，采集后统一转为 JPEG 并**清除 EXIF 元数据**（不携带设备与位置信息）；
- 采集与演示前后均确认画面内**不含任何个人信息**（证件、表格、聊天窗口等）。
