# ESP32 固件烧录说明

这是“光稳智检盒”最小硬件版本的固件。硬件不在手边时，网页默认运行模拟模式；硬件到手后再执行本页步骤。

下单型号见 `03_采购清单/最低成本采购清单_标签质检纸箱版.md`。初次安装请先按 `硬件安装一步一步.md` 操作；本页只说明固件、引脚和串口连接。

## 需要的软件

1. Arduino IDE 2.x
2. 在开发板管理器安装 `esp32 by Espressif Systems 3.x`
3. 在库管理器安装 `BH1750 by Christopher Laws`

## 接线

| 模块引脚 | ESP32引脚 | 作用 |
|---|---:|---|
| BH1750 VCC | 3V3 | 传感器供电 |
| BH1750 GND | GND | 共地 |
| BH1750 SDA | GPIO21 | I2C数据 |
| BH1750 SCL | GPIO22 | I2C时钟 |
| MOS模块PWM/SIG/TRIG输入 | GPIO25 | 仅在该模块资料确认它是兼容3.3V的PWM逻辑输入后连接 |
| MOS模块控制地 | ESP32 GND | 本方案使用的 MOS 模块控制端为 `IN+` / `IN-` 两个端子，`IN-` 即控制地，必须与 ESP32 的 GND 连通；若换用带光耦隔离输入的模块，控制地接法只按该模块自己的接线图决定，不能自行把隔离输入地与负载地短接 |
| 共阴RGB模块 G | GPIO26 | 正常状态，点亮绿色通道 |
| 共阴RGB模块 R | GPIO27 | 异常状态，点亮红色通道 |
| 共阴RGB模块 －/GND | GND | 共阴公共端；B脚不连接 |
| 有源蜂鸣器模块 VCC / GND | 3V3 / GND | 模块供电 |
| 有源蜂鸣器模块 IN/S | GPIO32 | 异常短鸣 |

灯带必须由独立5V电源供电，不能从ESP32的3V3引脚取电。MOS模块的负载端、控制端和是否隔离因型号而异；本说明不假设存在通用的 `DC+ / DC- / OUT+ / OUT-` 端子排列。必须按你手上模块的准确型号、端子丝印和对应接线图接灯带及电源，并确认PWM输入电压范围、有效电平、控制地接法和负载极性。资料不完整时不连接5V电源。

固件输出GPIO25 PWM信号，预期占空比越高灯带越亮；具体MOS模块是否满足这一逻辑，必须按其资料确认并在桌面上测试。GPIO26/27/32输出高电平时，对应RGB灯通道或蜂鸣器动作。因此RGB灯应选共阴四针且自带限流电阻的模块；蜂鸣器应选3.3～5V高电平触发的有源三针模块。RGB灯和蜂鸣器可以在第一轮调光测试后再接，不影响先验证 BH1750 读数与灯带调光。**注意：正式固件只支持手动 `LIGHT n` 调光，照度闭环尚未移植进固件**（闭环算法目前只在验证固件 `light_pwm_test` 与上位机 Python 上实测过）。

固件把灯带PWM固定为**8kHz**、8位分辨率（2026-10-07 由 1kHz 提高）。**已验证的部分：** 1kHz 下相机画面会出现 PWM 频闪横向条纹，逐行灰度波动标准差约 8.8 灰阶（见 `04_硬件验证记录/hardware-test-log.md`）。**未验证的部分：** 改成 8kHz 后**尚未重新采集逐帧数据复测**，"条纹基本消失"目前只是按单行曝光跨越多个 PWM 周期做的原理推断，需在实机上复测后确认。**注意：若换用额定频率 ≤1kHz 的模块（如 YYMOS-1），必须把频率改回 1kHz。** 只有模块资料明确支持该PWM频率、电压和有效电平时才可以使用；不同型号的端子排列不能互相套用。当前固件启动默认亮度为 **0%**（2026-10-09 由 45% 改为 0 并烧录验证：复位后回读亮度 = 0%），所以重启、USB 拔插、COM 口重连都不会再让灯带自己亮；要亮灯必须显式发 `LIGHT n`。改这条的原因是：原先复位回到 45%，导致「程序被强杀 / 端口开关」后灯带自己亮起来，实测反复出现过。

## 烧录与连接

1. 打开 `01_ESP32固件/lightguard_esp32.ino`。
2. 选择对应的ESP32开发板和串口。
3. 上传程序，保持USB线连接电脑。
4. 启动光稳智检网页，在“光照硬件终端”选择“ESP32串口实物”。
5. 选择对应COM口并点击“连接”。

串口速率固定为115200。连接成功后，网页可读取BH1750照度、调节灯带并控制红绿灯和蜂鸣器。
