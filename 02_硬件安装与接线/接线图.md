# 接线图（光稳智检 · 硬件验证）

> 本文档只用于**硬件验证**，不改动已提交的「光稳智检」比赛系统。
> 所有接线**断电操作**，接完先目视检查再上电。

---

## 0. 总览："一次只接一个"

```
第一步：只有 ESP32 + USB 线          → esp32_blink_test    （已通过 ✅）
第二步：ESP32 + BH1750               → bh1750_test
第三步：ESP32 + MOSFET + 灯带        → light_pwm_test     （MODE 0 固定 PWM）
第四步：第二步 + 第三步 一起          → light_pwm_test     （MODE 1 照度闭环）
第五步：加红绿指示灯（可先用板载 LED）
```

**不要一次性全接上。** 每接一个器件就单独跑一次对应的固件，确认通过再往下走。
否则出问题时无法判断是哪一根线的问题。

## 1. BH1750 光照传感器（I2C，3.3V）

```
        BH1750 模块 (GY-302)                ESP32 DevKit
      ┌───────────────────────┐          ┌──────────────┐
      │  VCC  ●────────────────┼──────────┼─● 3V3        │
      │  GND  ●────────────────┼──────────┼─● GND        │
      │  SDA  ●────────────────┼──────────┼─● GPIO21     │
      │  SCL  ●────────────────┼──────────┼─● GPIO22     │
      │  ADDR ○── GND           │          │              │
      └───────────────────────┘          └──────────────┘
                                            USB → 电脑 (COM5)
```

| 要点 | 说明 |
|---|---|
| 供电 | **必须 3V3**，不要接 5V（模块虽多有电平转换，但 3.3V 最稳） |
| ADDR 脚 | **接 GND** = 地址 `0x23`（数据手册定义的接法，推荐）；接 VCC = 地址 `0x5C`。悬空在多数模块上也能读到 `0x23`，但不如接地可靠。固件两种地址都自动识别 |
| 上拉电阻 | GY-302 模块自带上拉；裸 BH1750 芯片需在 SDA/SCL 各加 4.7kΩ 上拉到 3V3 |
| 杜邦线 | 尽量短（<20cm），线长容易导致 I2C 读失败 |

**通过标准**：串口每 500ms 一行 `LUX:xxx.x`；用手机手电筒照一下，数值明显变大；用手捂住，数值明显变小。

## 2. MOSFET / 灯带驱动（PWM 调光）

> ⚠️ **灯带绝对不能直接接 ESP32 GPIO。** GPIO 只能输出 3.3V / 几十 mA 的**信号**；
> 灯带工作电流可达 1~5A，直连会瞬间烧毁 IO 甚至整颗芯片。

```
                5V 独立电源
              ┌──────────────┐
              │  +5V     GND │
              └───┬────────┬─┘
                  │        │
                  │        ├───────────────► ESP32 GND      （★ 必须共地！）
                  │        │
                  │        └───────────────► MOSFET 源极 S / GND
                  │
                  ▼
             ┌─────────┐
             │  灯带 +  │
             │         │
             │  灯带 −  │────────► MOSFET 漏极 D / OUT
             └─────────┘

   ESP32 GPIO25 ────────────────────► MOSFET 栅极 G / SIGNAL
```

**信号流向**：`GPIO25 → 栅极 G → 控制 D-S 通断 → 灯带电流由 5V 电源经灯带、MOSFET 回到电源负极`。
ESP32 只出力，不出电流。

| 要点 | 说明 |
|---|---|
| ★ 共地 | ESP32 的 GND 必须接到 5V 电源负极。不共地 = PWM 信号没有参考电平，表现是灯常亮/乱闪/不响应 |
| MOSFET 选型 | 用**逻辑电平** MOSFET：`IRLZ44N`、`AO3400`、`IRL540N`；成品模块可选"MOS 管驱动模块"。**不要用 IRF520**（5V 下阈值电压偏高，会半开半闭发烫） |
| 栅极电阻 | 栅极串 100Ω 左右，栅源并 10kΩ 下拉，可避免上电瞬间乱闪 |
| 灯带电源 | 单独 5V 电源，电流按 `灯带长度 × 每米电流` 留 1.5 倍余量 |
| 单色灯带 | 只需要 1 路 PWM（GPIO25） |
| 灯带类型 | **本项目用单色（单通道）灯带，只占 1 路 PWM（GPIO25）**。如果以后改用共阳 RGB 灯带做补光，需要重新分配 3 路 PWM 并避开 GPIO26/27（已被红绿指示占用），属于方案变更，不在本次验证范围内 |

**通过标准**：MODE 0 下亮度按 0→25→50→75→100% 循环变化，串口同步打印 `BRIGHTNESS:xx`，全程无闪烁、MOSFET 不发烫。

## 3. 正常 / 异常指示（共阴 RGB 模块 + 有源蜂鸣器）

先用**板载 LED（GPIO2）**验证逻辑，逻辑对了再换外部指示模块。

```
        共阴 RGB 模块                         ESP32 DevKit
      ┌────────────────┐                    ┌──────────────┐
      │  G  ●──────────┼────────────────────┼─● GPIO26     │  绿 = 正常
      │  R  ●──────────┼────────────────────┼─● GPIO27     │  红 = 异常
      │  -  ●──────────┼────────────────────┼─● GND        │  共阴公共端
      │  B  ○ 不连接    │                    │              │
      └────────────────┘                    │              │
                                             │              │
        有源蜂鸣器模块(3针)                    │              │
      ┌────────────────┐                    │              │
      │  VCC ●─────────┼────────────────────┼─● 3V3        │
      │  GND ●─────────┼────────────────────┼─● GND        │
      │  IN/S ●────────┼────────────────────┼─● GPIO32     │  异常短鸣
      └────────────────┘                    └──────────────┘
```

| 要点 | 说明 |
|---|---|
| ★ 红绿不要接反 | **GPIO26 = 绿 = 正常**，**GPIO27 = 红 = 异常**（与 `01_ESP32固件/固件说明.md` 一致）。接反了演示时会"检出缺陷亮绿灯" |
| RGB 模块选型 | 选**共阴、四针、自带限流电阻**的模块；`B` 脚不接（本方案只用红/绿两态） |
| 蜂鸣器选型 | **有源**（自带振荡）三针模块，3.3~5V **高电平触发**；不要买无源蜂鸣器（需要 PWM 驱动才响） |
| 单颗 LED 替代方案 | 若直接用两颗 LED：`GPIO26 ── 330Ω ── 绿LED ── GND`、`GPIO27 ── 330Ω ── 红LED ── GND`，同样不要接反 |
| 大功率指示灯 | 要驱动大功率灯，必须经 MOSFET/三极管，不要直连 GPIO |

**通过标准**：发送 `RESULT NORMAL` 亮绿灯（蜂鸣器不响）、发送 `RESULT ABNORMAL` 亮红灯并短鸣、发送 `RESULT IDLE` 熄灭，结果保持到下一次指令。（命令用**空格**分隔，不是冒号；固件只识别 `NORMAL` / `ABNORMAL` / `IDLE`，写成 `RESULT:...` 会收到 `{"ok":false,"error":"unknown command"}`，写成 `RESULT DEFECT` 会收到 `{"ok":false,"error":"result must be NORMAL, ABNORMAL or IDLE"}`。）

## 4. 上电前检查清单（每次接线后都过一遍）

- [ ] 电源正负极没有接反
- [ ] ESP32 的 GND 与外部电源 GND **已连通**（用万用表蜂鸣档量一下）
- [ ] 灯带没有直接接在 GPIO 上
- [ ] 3V3 供电的模块没有误接 5V
- [ ] 杜邦线插到位、没有相邻短路
- [ ] 先接 USB 只上逻辑电、确认串口正常，再接 5V 灯带电源

## 5. 每次上电/复位前必看（这条最容易出事）

正式固件 `lightguard_esp32.ino` **启动默认亮度是 0%**（2026-10-09 已改为 0 并烧录验证；
在此之前是 45%，会导致复位瞬间自己亮）。

> ⚠️ 所以：**每次 ESP32 重启、拔插 USB、COM 口重连之前，先断开灯带 5V 电源**。
> 改之前复位瞬间灯带会自己亮到 45%（晃眼、发热、白耗电，还干扰判断）；改后不会了。
> 但要调光仍然必须显式发 `LIGHT n` —— 固件不会自己点灯。

本验证库的 `light_pwm_test` 启动默认是 0%（安全），但只要你烧回了正式固件，这条就重新生效。

## 6. 实物核对：本项目实际使用的 MOS 模块（2026-10-05 照片核对）

**型号**：蓝色 PCB 大功率 MOS 管 PWM 驱动模块（板上可读丝印含 `MOS-1`，与采购清单中
`XY-MOS 大功率MOS管模块 PWM调光调速 5-36V 3.3V触发` 同类）。实物特征：4 位螺丝端子 +
2 位螺丝端子 + 无旋钮（无旋钮这点很关键 —— 有旋钮的是手调调速器，ESP32 控制不了）。

**端子定义（★ 接线时只认端子旁边印的字，不要按左右顺序猜）**：

| 端子丝印 | 接什么 | 说明 |
|---|---|---|
| `DC+` | 5V 适配器 **正极** | 电源输入 |
| `DC-` | 5V 适配器 **负极** | 电源输入（同时是模块地） |
| `OUT+` | 灯带 **正极** | 负载输出 |
| `OUT-` | 灯带 **负极** | 负载输出（模块内部在这个回路上做开关） |
| `IN+` | ESP32 **GPIO25** | PWM 信号输入 |
| `IN-` | ESP32 **GND** | 信号地 |

**⚠️ `IN+` / `IN-` 接反的后果**：`IN-` 在模块内部直接连模块地。把 GPIO25 接到 `IN-`
= **把 GPIO25 短路到地**，可能烧掉这个引脚。所以正式上电前必须确认这两个脚的极性：

1. **看丝印**：模块平放，把竖排小字转成"横着能读"的方向，读出每个脚旁边是 `IN+` 还是 `IN-`；
2. **用电自检（推荐，零风险）**：烧 `01_ESP32固件/mos_polarity_probe/`，接 3 根线
   （`GPIO25→端子A`、`GPIO26→端子B`、`ESP32 GND→DC-`，**不接 5V、不接灯带**），
   串口会直接告诉你是哪个端子是 `IN-`。
   原理：两个脚全程只做"输入 + 内部弱上拉"，**不输出、不驱动**；读到 LOW 的那个脚
   所连端子内部就是模块地，即 `IN-`（LOW=IN-，HIGH=IN+）。接反也不会短路。

**上电顺序（必须照做）**：

```
1) 拔掉 5V 适配器 → 按上表接线 → 检查无散铜丝、无相邻端子搭接、极性无接反
2) 只插 ESP32 USB → 烧 light_pwm_test（MODE 0）→ 串口确认亮度显示 0%
3) 最后才插 5V 适配器 → 灯带应保持 **0%（不亮）**；这是验证固件的安全启动设计，**不会自动开始循环**，需要在串口监视器里发一条 `B:` 或 `A` 命令后才会按 0→25→50→75→100% 变化。若一上电就自己亮起来，说明接线或模块极性有问题，立刻断电检查
4) 出现 模块发烫 / 异味 / 灯带常亮不受控 → 立刻拔 5V，不要带电换线
```

**与正式固件的兼容性**：`lightguard_esp32.ino` 把 PWM 固定为 **8 kHz / 8 位**
（2026-10-07 由 1 kHz 提高，原因见 `hardware-test-log.md` §2.13：1 kHz 下相机画面出现 PWM
频闪横向条纹；**改为 8 kHz 后尚未重新采集逐帧数据复测，条纹是否消除待实机确认**）。本模块资料标称支持 **0~20 kHz** PWM 输入、**3.3~20V** 信号、
**5~36V** 负载，因此 8 kHz 与 3.3V 信号都在允许范围内；`light_pwm_test` 已按同样参数对齐，
两个固件切换时不需要改任何接线。**若换用额定频率 ≤1 kHz 的模块（如 YYMOS-1），必须改回 1 kHz。**
