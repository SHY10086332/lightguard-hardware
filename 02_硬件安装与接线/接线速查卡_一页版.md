# 接线速查卡（一页版）

> 打印或放在桌上，接线/演示时照着看。适用于本项目实际使用的那套硬件。

## 0. 本机关键参数（不用记，但要一致）

| 项 | 值 |
|---|---|
| 板型 | **ESP32 Dev Module**（`esp32:esp32:esp32`） |
| 串口 | **COM5**（CP2102），速率 **115200** |
| 芯片 | ESP32-D0WD-V3，双核 240MHz，Flash 4MB |
| PWM | **8 kHz / 8 位**（`lightguard_esp32.ino` 与 `light_pwm_test` 一致；1kHz 会有相机条纹） |
| 烧录 | **每次都要手动按 BOOT**（本板无自动下载电路） |

## 1. ESP32 引脚分配

| GPIO | 接什么 | 方向 |
|---|---|---|
| GPIO21 | BH1750 `SDA` | I2C 数据 |
| GPIO22 | BH1750 `SCL` | I2C 时钟 |
| GPIO25 | MOS 模块 `IN+` | PWM 信号输出 |
| GPIO26 | RGB 模块 `G`（**绿灯 = 正常**） | 输出 |
| GPIO27 | RGB 模块 `R`（**红灯 = 异常**） | 输出 |
| GPIO32 | 有源蜂鸣器 `IN`（异常短鸣） | 输出 |
| GPIO2 | 板载 LED（自检用） | 输出 |
| GND | **公共地**：必须与 5V 电源负极连通 | — |
| 3V3 | BH1750、蜂鸣器模块供电 | — |

## 2. 三块器件的接线

### BH1750（照度）
```
VCC → 3V3      GND → GND      SDA → GPIO21      SCL → GPIO22      ADDR → GND（0x23）
```

### MOS 模块 + 灯带 + 5V 电源
```
5V适配器 正极 → DC+          灯带 正极 → OUT+
5V适配器 负极 → DC-          灯带 负极 → OUT-
ESP32 GPIO25  → IN+          ESP32 GND → IN-
```
> ★ `IN+` / `IN-` 接反 = 把 GPIO25 短路到地，可能烧引脚。
> 不确定时先烧 `mos_polarity_probe` 自检（接 `GPIO25→A`、`GPIO26→B`、`GND→DC-`，不接 5V）。

### RGB + 蜂鸣器（最后再接）
```
RGB 共阴模块: G → GPIO26    R → GPIO27    -/GND → GND    B 不接
有源蜂鸣器  : VCC → 3V3     GND → GND     IN/S → GPIO32
```

## 3. 烧录三步（本板必须按 BOOT）

```
① 按住 BOOT 不放
② 点“上传”（或运行 flash_manual.ps1，它会等你按）
③ 看到日志出现 Writing at 0x00001000... → 松开 BOOT
```
串口监视器用 **115200**。网页连 ESP32 时，**必须关掉 Arduino 串口监视器**（同一个 COM 口不能被两个程序占用）。

## 4. 点灯带的固定顺序（照做，别跳）

```
① 拔掉 5V 适配器 → 按上表接线 → 检查无散铜丝、无相邻端子搭接
② 只插 ESP32 USB → 烧 light_pwm_test → 串口确认亮度显示 0%
③ 最后才插 5V 适配器 → 灯带保持 0%（安全启动，不自动循环）；发一条 `B:`/`A` 命令后才开始 0→25→50→75→100% 变化
```

## 5. 三条红线

1. **灯带绝不直连 GPIO**，必须经 MOS 模块；**ESP32 GND 必须与 5V 电源负极共地**。
2. ~~每次 ESP32 复位 / 拔插 USB / 串口重连之前，先断开灯带 5V~~ —— **已不需要**：
   正式固件默认亮度 **0%**（2026-10-09 烧录验证），复位不会再自己亮。
3. **`IN±` 极性没确认前不接 5V**；模块发烫、有异味、灯带常亮不受控 → **立刻拔 5V**，不要带电换线。

## 6. 出问题先看这张表

| 现象 | 先做什么 |
|---|---|
| 编译报 `exec: "cmd": executable file not found in %PATH%` | 系统 PATH 缺 `C:\Windows\System32`；补上并**重启 Arduino IDE** |
| 上传卡 `Connecting......` 然后报 `Wrong boot mode (0x13)` | 没按 BOOT。按住 BOOT → 按一下 EN → 松开 BOOT，再用 `flash_manual.ps1` |
| 串口读不到 `LUX:` | 断 USB，复查 BH1750 四根线；确认 `VCC` 在 `3V3` 不是 `5V` |
| `LUX` 一直是 0 或不变 | 用手遮住感光面再移开；仍不变则断电复查 SDA/SCL 是否接反 |
| 灯带不亮 / 常亮不受控 | 立即拔 5V；核对 `IN+`/`IN-` 极性、`DC±`/`OUT±` 是否接错 |
| 模块或线发热、有异味 | 立即断开 5V 和 USB；不要再次通电，先拍照确认 |
| 网页读不到照度 | 关掉 Arduino 串口监视器；确认选的是 COM5；确认固件是正式固件（验证固件用的是文本协议，网页不认） |
