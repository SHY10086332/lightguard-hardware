# 光稳智检盒：零基础硬件安装步骤

这份说明只讲怎样把现有硬件一步步装起来。按顺序做，每完成一部分先检查，再进入下一部分。第一版先实现：**摄像头拍清标签 + BH1750读照度 + ESP32调节灯带**。RGB灯和蜂鸣器可以最后再接，不影响先把主作品跑起来。

## 本机实测环境（2026-10-04，动手前先看这段）

下面四条是**在实物上实测**出来的，和采购清单或原始设想可能不同，**以本节为准**：

| 项 | 实测结果 | 对安装的影响 |
|---|---|---|
| 串口芯片 | **CP2102**（`Silicon Labs CP210x USB to UART Bridge (COM5)`）；采购清单原写的是 CH340 版 | CP210x 驱动已就绪，**不需要再装 CH340 驱动**。以后若换板子要注意驱动不同 |
| 芯片型号 | `ESP32-D0WD-V3` rev v3.1，双核 240MHz，**Flash 4MB**，SDK v5.5.5 | 与"ESP32 Dev Module"板型一致 |
| 下载模式 | **本板没有自动下载电路**，不按 BOOT 会报 `Wrong boot mode detected (0x13)` | 烧录必须手动按 BOOT（见第3步）。这是硬件设计，不是板子坏 |
| 系统 PATH | 原先缺少 `C:\Windows\System32`，编译报 `exec: "cmd": executable file not found in %PATH%` | 已修复，**修完必须重启 Arduino IDE 才生效** |

详细的原始证据（esptool 识别输出、四个镜像 Hash 校验、串口启动日志）见
`04_硬件验证记录/hardware-test-log.md`；引脚分配见 `02_硬件安装与接线/引脚表.md`；
各器件接线图见 `02_硬件安装与接线/接线图.md`。

## 先看懂整套东西怎么连

```text
摄像头 ──USB线──> 电脑（拍标签）
ESP32   ──USB线──> 电脑（烧程序、收发控制命令）
BH1750  ──4根小信号线──> ESP32（测量照度）
ESP32 GPIO25 ──控制信号──> PWM MOS模块（调灯亮度，端子需看实物确认）
5V适配器 ──电源线──> PWM MOS模块 ──电源线──> 5V灯带
```

**注意：电脑USB线接ESP32开发板上的USB插口，不是接GPIO25。GPIO25是ESP32排针上的一个控制信号脚。**

## 开始前：把东西摆出来

准备：纸箱、A4纸、标签打印纸、摄像头、ESP32、BH1750、PWM MOS模块、5V灯带、5V适配器、DC5521母座线、面包板、杜邦线、胶带、剪刀、小螺丝刀和硬纸板。

先做这三件事：

1. 给5V适配器拔掉电源，ESP32也先不要插电脑。
2. 找一张桌子，把纸箱、控制板和电源放在桌面上。接线和首次点灯时，灯带、适配器、控制板都放在纸箱外。
3. 暂时不剪灯带、不剪纸箱、不拧MOS端子、不把东西粘死。摄像头、灯带都要先试位置。

不要拆开5V适配器外壳，也不要接触220V市电。修改任何接线前，都要同时拔掉ESP32 USB线和5V适配器。

## 第1步：给纸箱和A4纸做定位

1. 用直尺量纸箱里面的宽、深、高。当前设计目标是**内宽365mm、内深490mm、内高315mm**；如果实物不同，记录实测尺寸，不要量纸箱外侧来代替。
2. 打开纸箱，把A4纸平放在箱底中央：纸的297mm长边沿箱子的365mm宽边，210mm短边沿490mm深边。
3. 把A4纸左右、前后挪到大致居中。用四小段胶带在箱底贴出纸张四角的位置线。
4. 把 60mm × 40mm 标签打印在A4纸上（见 `05_数据集与标签设计/print/`），放回定位线内。以后每次换样品，都把A4纸放回同一组线内。

**检查：**纸没有卷起，标签在箱底中间附近。此时箱顶和侧壁都不要开孔。

下面是箱底的俯视摆放关系（不按比例）：

```text
                    箱后侧，内宽约365mm
       +------------------------------------+
       | 灯带沿后侧摆放                   灯带|
       |                                    |  箱深
       |       +--------------------+       |  约490mm
       |       |                    |       |
       |灯带   |   A4纸 297×210mm   |  灯带|
       |       |      +--------+    |       |
       |       |      | 60×40  | BH |       |
       |       |      | 标签   |    |       |
       |       +--------------------+       |
       |                                    |
       +------------------------------------+
                    箱前侧
```

A4纸的297mm边沿箱宽方向，210mm边沿箱深方向。灯带先沿箱内左右侧壁和后侧上部试摆；BH1750靠标签旁边放，感光面朝上，不遮住标签或相机视线。摄像头在标签正上方，朝下拍摄。

## 第2步：先试摄像头，暂时不装灯带

1. 用摄像头自己的USB线把摄像头接到电脑。摄像头不接ESP32，也不接面包板。
2. 先用Windows自带的“相机”应用确认新买的USB摄像头能出画面，然后关闭“相机”应用。再打开项目网页并允许浏览器使用摄像头；如果浏览器权限/站点设置提供摄像头下拉选项，选择USB摄像头。项目网页当前没有自己的摄像头选择菜单，如果预览仍来自笔记本内置摄像头，先停下反馈，不要把错误画面当成外接相机已测试。
3. 把A4纸放回箱底定位线。用两层硬纸板做一条临时横梁，横跨纸箱开口；用胶带把横梁两端固定在箱沿上。再把摄像头固定在横梁下方，让镜头垂直朝下、对准标签中心。摄像头不能只松松地搭着，避免掉进箱子。
4. 箱内高约315mm时，用直尺量“镜头最前端到A4纸面”的垂直距离。镜头靠近箱口时约为305～315mm，先看电脑预览，不要按网店视角参数推算孔位。
5. 分开检查画面大小和清晰度：标签太小就把横梁降低一点；标签边缘被裁掉就把横梁升高一点；文字模糊时，若镜头支持手动调焦，先轻微调整镜头焦环，再重新看预览。每次只改一项。
6. 画面达到“标签完整、居中、文字可辨认、边缘没有被切掉”后，记下横梁高度。再用一张自己做的最小缺陷样纸（例如一条细断线）确认缺陷在画面中也看得见。

**检查：**连续预览一分钟，画面不黑屏，标签不随横梁晃动。若镜头在约305～315mm处不能对焦，先试着降低横梁；仍然不清楚时，把摄像头型号和实拍预览发来确认。此时只做临时试拍，不开孔、不固定相机。

### 现在先不要开孔

第2步只确认相机能拍清楚，不是最终安装。要等第7步把灯带临时放好、合上箱盖检查反光、并且确定镜头高度不再调整后，再按第8步选一种最终安装方式。不要把USB插头直接穿过纸箱；通常可先让细线从箱盖边缘临时引出，再按线缆粗细决定是否开走线小孔。

## 第3步：给ESP32烧程序

如果ESP32已经烧好项目固件，可以跳过烧录，只做下面第4步。

**先分清“要装库”和“不用装库”两件事：**

| 固件 | 要不要在库管理器装 `BH1750 by Christopher Laws` |
|---|---|
| 正式固件 `lightguard_esp32.ino` | **要**（源码里有 `#include <BH1750.h>`） |
| 验证固件 `bh1750_test` 等（本包 `01_ESP32固件/` 下） | **不要**（驱动自带，干净环境也能直接编译） |

1. 先确认USB线是“可传数据”的线，再把ESP32开发板的USB插口接到电脑。
2. 安装 Arduino IDE 2.x，并在开发板管理器里安装 `esp32 by Espressif Systems 3.x`（本板烧录注意事项与排错见 `04_硬件验证记录/README.md`）。
3. 在Arduino IDE打开 `01_ESP32固件/lightguard_esp32.ino`，并在库管理器安装 `BH1750 by Christopher Laws`。
4. 选择开发板 **ESP32 Dev Module** 和它对应的COM串口（本机为 **COM5**），点击“上传”。
5. **上传时要按住 BOOT**：按住 BOOT 不放 → 点“上传” → 看到日志出现 `Writing at 0x00001000...` 再松开 BOOT。
   不按会报 `Wrong boot mode detected (0x13)`——本板没有自动下载电路，这是正常现象，不是板子坏。
   也可以用 `01_ESP32固件/flash_manual.ps1`，它会自动编译并一直等你按 BOOT：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\flash_manual.ps1 -Sketch .\bh1750_test
   ```
6. 上传完成后，关闭Arduino的串口监视器。网页连接ESP32时不能同时有另一个程序占用同一个COM口。

**检查：**Arduino IDE显示上传成功。暂时不要接5V灯带电源。

> 若编译报 `exec: "cmd": executable file not found in %PATH%`，说明系统 PATH 又缺了 `C:\Windows\System32`，
> 补回去并**重启 Arduino IDE**（本机 2026-10-04 已修过一次，见开头“本机实测环境”）。

## 第4步：只接BH1750，先验证照度

接线时先从电脑拔下ESP32 USB线。BH1750板上的引脚文字可能在正面或背面，先认清 `VCC`、`GND`、`SDA`、`SCL`，不要只凭引脚左右位置猜。

| BH1750板上的字 | 接到ESP32板上的字/脚 | 这根线的用途 |
|---|---|---|
| VCC | 3V3 | 给传感器供电，**不要接5V** |
| GND | GND | 地线 |
| SDA | GPIO21 | I2C数据 |
| SCL | GPIO22 | I2C时钟 |

> **`ADDR` 脚接到 GND**（地址 `0x23`，这是数据手册定义的接法；悬空在多数模块上也能读到 `0x23`，但不如接地可靠）。验证固件会自动识别 `0x23` 和 `0x5C` 两种地址。
>
> **推荐先用验证固件单独验证传感器，再烧正式固件接网页**，这样出问题时能确定是"传感器/接线"还是"网页/固件"的问题：
> ```powershell
> cd "<材料包>\aic AI+硬件\01_ESP32固件"
> powershell -ExecutionPolicy Bypass -File .\flash_manual.ps1 -Sketch .\bh1750_test
> ```
> `bh1750_test` **不需要装 BH1750 库**，烧好后串口监视器（115200）会持续输出 `LUX:xxx.x`。
> 注意它的输出是 `LUX:450.2` 这种文本格式，**和正式固件的 JSON 协议不通用**（正式固件回的是
> `{"ok":true,"lux":450.2,...}`），所以不要用网页去连验证固件。

1. ESP32插在面包板上时，让两排针脚分别插在中间凹槽两边；不要把整块板的针脚插进同一组相连孔里。
2. 用四根杜邦线逐根连接上表。每接一根，就沿着线从传感器端找到ESP32端，确认两头名字正确。
3. 检查 `VCC`确实到`3V3`，没有碰到`5V/VIN`；四根裸露金属没有互相碰到。
4. 检查后，把ESP32 USB线接回电脑，打开项目网页，在“光照硬件终端”选择“ESP32串口实物”，选择ESP32的COM口后点“连接”。
5. 页面出现lux读数后，用手短暂遮住BH1750感光面，再移开。页面读数应有变化。

**检查：**lux读数能显示，遮住和放开传感器时读数会变化。若不变化，先拔USB，依次复查四根线；不要因此继续接灯带。

## 第5步：确认灯带、适配器和MOS模块

灯带回路电流较大，不能走面包板或细杜邦线。接错可能烧坏模块或导线发热，所以这一步要先确认型号。

> 接线示意图（BH1750 / MOS+灯带 / RGB+蜂鸣器 三张图，含上电前检查清单）见 `02_硬件安装与接线/接线图.md`；
> 每个 GPIO 的用途、禁用引脚、PWM 参数对照见 `02_硬件安装与接线/引脚表.md`。
> 这两份是"照着实接"的版本，本步骤的型号核对结论要回填到那里再动手。

逐项检查包装或商品信息：

- 电源适配器输出标明 **5V直流**，不是12V或24V；
- 灯带标明 **5V、单色、两根电源线**；
- 知道灯带的总功率或总电流；
- MOS模块支持ESP32的3.3V PWM控制，支持5V负载，额定电流大于灯带实际电流并留有余量；
- 知道MOS模块准确型号；看得到每个端子的名称和对应接线图，并确认输入电压范围、PWM有效电平、是否隔离、控制地接法和5V负载端接法；
- DC5521母座线的插头尺寸能和适配器相配；适配器极性按外壳标记确认，不能只凭线色猜。

**任何一项不清楚，都停在这里，不插5V适配器。**请拍MOS模块正面、背面、端子文字和商品接线图。不同板子的端子顺序不同；没有这些照片，不能安全地告诉你哪根线拧到哪个端子。

### 看懂信号线和电源线的区别

```text
电脑的USB口 --USB数据线--> ESP32开发板的USB插口
ESP32排针 GPIO25 --一根控制信号线--> MOS模块PWM/SIG/TRIG输入
ESP32 GND --控制参考地--> MOS控制端地（只按该模块接线图确认）

5V适配器 --较粗的电源线--> MOS负载电源端
MOS负载输出 --较粗的电源线--> 5V灯带两根电源线
```

图中“GPIO25”只是一根控制信号的来源，**不是给灯带供电的地方**。图示不是MOS端子排列图。某些模块输入侧和负载侧隔离，不能自行把两侧地线短接；是否共地要看该板说明。

纸箱内相机和灯带的上下关系（侧视图，不按比例）：

```text
          箱盖/箱口
     摄像头镜头朝下
            ↓
     灯带 → 侧壁（不直射镜头）
            ↓ 约305～315mm，先实测
     -------------------- A4纸/标签
          箱底
```

## 第6步：灯带回路确认后再短时点亮

只有MOS端子图已确认后才做这一步。第一次测试在桌面上完成，灯带和纸箱分开放，旁边有人看着。

1. 拔下ESP32 USB线，拔掉5V适配器；确认电源插头与插座分开。
2. 按已确认的MOS接线图接线。灯带和适配器的正负电源线走MOS的负载端子，使用模块要求的线径；不要插到面包板上。
3. GPIO25只接MOS图纸标明的PWM/SIG/TRIG控制输入。控制地如何连接也按该板图纸，不要自行猜共地。
4. 拧紧端子后检查：没有散出的铜丝、正负没有接反、相邻端子之间没有铜丝搭接。
5. ESP32接电脑USB，打开网页，把“光照硬件终端”切到“ESP32串口实物”，在串口列表选择ESP32对应COM口并点“连接”。灯带5V适配器仍保持拔掉。确认状态标记显示“ESP32实物”，再把亮度设为0%，确认页面显示0%后才继续。固件启动默认亮度是 **45%**，不是0%或10%；串口重连也可能让ESP32复位回45%，所以每次重启、拔插USB或重新连接COM口前，都先拔掉灯带5V适配器。
6. 确认5V适配器铭牌、灯带和MOS规格无误后，插上5V适配器，短时观察灯带。若模块重启、灯带忽明忽暗、异味、线材或模块发热，立即拔掉5V适配器；断电后再检查。
7. 想再次给ESP32断电或重启前，先拔掉5V灯带电源。重启后固件会回到45%默认亮度；带着灯带电源时，不要依赖网页滑块保持低亮度。

**检查：**网页调高亮度时灯带变亮，调低时变暗，设为0时灯带熄灭。若灯带常亮或不受控，立即拔掉5V适配器，不要带电换线。

## 第7步：灯带试摆到箱内

桌面短时点亮正常后，先断开5V适配器和ESP32 USB，再把灯带放进箱内试位置。不要马上剪灯带或撕掉背胶。

1. 沿纸箱左右侧壁上部和后侧试摆成U形。1米灯带可以先试后侧约365mm、左右各约250mm的路线，拐角不要硬折，电线端留出余量。
2. 灯珠朝侧壁或斜向下，不要让灯珠直接照进摄像头，也不要压住纸张、BH1750或标签。
3. 用胶带临时固定，合上箱盖看摄像头画面。若出现白色亮斑、反光或阴影，先转动灯带或改变高度。
4. 给BH1750做临时标记。先保持5V灯带适配器拔掉，给ESP32接USB；网页中把“光照硬件终端”切到“ESP32串口实物”，选择正确COM口并点“连接”，确认状态标记显示“ESP32实物”，再把亮度设为0%。之后插入5V适配器，将灯带设到较低亮度，再依次把传感器放在标签中心、左前、右前、左后、右后，记下5个lux读数。先用胶带把BH1750固定在一小片硬纸板上，感光面露出来；移动硬纸板，不要碰传感器排针或拉扯杜邦线。
5. 读完5个位置后，先拔掉5V灯带适配器，再把BH1750固定在标签旁、与纸面大致同高、感光面朝上且不被遮挡的位置。若还要拔ESP32 USB或改接线，必须确认5V适配器已拔掉；之后每次测试都把传感器放回这里。
6. 如果5点亮度差异很大，先把5V适配器和ESP32 USB都拔掉，再移动灯带；仍然有强烈亮斑才试加描图纸。描图纸不要紧贴灯带，避免积热。重新测试时按第6步的上电顺序重来。BH1750固定在一个位置后，自动控制稳定的是传感器位置的读数，不代表标签全区域照度都一样。
7. 位置稳定后准备复测：先确认5V适配器拔着；如果ESP32曾断电或网页串口断开，先接USB、切换到“ESP32串口实物”并连接正确COM口。然后在页面把亮度设为0%并确认仍是实物已连接，最后才插入5V适配器，再逐渐调到需要的亮度。首次连续点亮至少10分钟并全程有人看管；纸箱、胶带或电线明显发热、胶带变软或有气味时立即拔掉5V适配器。无人看管时关闭5V灯带电源。

## 第8步：最后固定相机和封箱

1. 在灯光已摆好后重新检查相机预览，确认标签仍然完整、居中、清晰。
2. 选定一种固定方式，不要把两种混在一起：A. 相机主体固定在箱盖外侧，只有镜头通过箱盖上的小孔；B. 相机固定在箱内的硬纸板横梁上，不开镜头孔。横梁要固定牢靠，不能被箱盖压到。
3. 只有选方式A时才开镜头小孔，按镜头外径开到刚好能通过，孔边贴硬纸板加固。USB线先从盖缝临时引出；确实需要开走线孔时，只按细线外径开小孔，不让USB插头穿孔。用胶带封住明显漏光缝。
4. 合上箱盖再看一次画面，确保箱盖没有碰镜头、压线或压灯带；A4仍落在底部定位线内。
5. ESP32、面包板、MOS模块和适配器放在纸箱外，不能塞在灯带旁边或压在纸箱上。

## 第9步：基础验收

按表一项一项打勾。没通过的项目先修好，不要急着采集正式训练照片。

| 要检查什么 | 怎么检查 | 通过标准 |
|---|---|---|
| 摄像头 | 网页打开预览，重复开关或拍照20次 | 不黑屏，标签位置稳定、字清楚 |
| BH1750 | 遮住传感器再移开 | lux读数明显变化 |
| 手动调光 | 网页分别设置0%、低亮度和较高亮度 | 灯带熄灭、变暗、变亮顺序正确 |
| 纸张定位 | A4纸取出再放回定位线，重复5次 | 标签在画面里的位置基本不变 |
| 连续运行 | 有人看管运行10分钟 | 无明显发热、异味、冒烟、异常闪烁或胶带脱落 |

## 以后再接的部分：RGB灯和蜂鸣器

这两件不是第一轮必需。等相机、BH1750和灯带都正常后再接，并且每次接线前拔掉ESP32 USB和5V灯带电源。

| 模块 | 固件预留引脚 | 接线前必须确认 |
|---|---:|---|
| RGB绿色通道 | GPIO26 | 模块是共阴且自带限流电阻，G脚标识清楚 |
| RGB红色通道 | GPIO27 | 同上，R脚标识清楚 |
| RGB蓝色通道 | 不接 | 第一版不用 |
| 有源蜂鸣器信号 | GPIO32 | 3.3V可用、高电平触发、有驱动电路 |

RGB公共端、蜂鸣器电源和地线按各自模块标识及说明连接。若模块标识不符合表中条件，先不要接；不确定就先跳过，不影响核心作品运行。

## 常见问题先怎么处理

| 现象 | 先做什么 |
|---|---|
| 网页没有lux | 确认ESP32连接的是正确COM口；关闭Arduino串口监视器；断USB后复查BH1750四根线 |
| lux一直不变 | 用手遮住BH1750再移开；仍不变就断电复查VCC、GND、SDA、SCL |
| 网页找不到摄像头 | 摄像头必须直接插电脑USB；检查浏览器权限，并选外接USB摄像头 |
| 灯带不亮或常亮 | 立即拔5V适配器；按该MOS板接线图核对电源输入、负载输出、控制输入和极性 |
| 线发热、有异味、冒烟 | 立即断开5V适配器和ESP32 USB；不要再次通电，拍清楚模块和接线后检查 |
| 纸箱内有明显亮斑 | 先断电调整灯带方向/高度，再观察；需要时加与灯带留有间距的描图纸 |

## 接线不确定时需要拍什么

如果不知道MOS模块怎么接，先不要插5V。拍下面几张清晰照片发来：

1. MOS模块正面全图，端子名称和小字能看清；
2. MOS模块背面全图；
3. 商品页面中说明端子接法的图片；
4. 5V适配器铭牌、灯带电源线标记，以及MOS模块型号。

在核对这些信息之前，只完成纸箱定位、摄像头试拍、ESP32烧录和BH1750测试。这样已经能先把大部分作品搭起来，不需要猜电源线接法。
