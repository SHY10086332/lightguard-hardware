# 引脚表（ESP32 DevKit · 本项目实物为 38pin 双列；30/40pin 板的同名 GPIO 位置相同，本表引脚号通用）

芯片实测：`ESP32-D0WD-V3` rev 301，双核 240MHz，Flash 4MB（DIO @80MHz）。

> **本表与 `01_ESP32固件/固件说明.md` 的引脚规划完全一致**，是它的"实测验证版"。
> 两处如有不一致，以本表为准并回头修正固件说明。

## 一、本项目使用的引脚

| 功能 | GPIO | 方向 | 固件中的宏 | 备注 |
|---|---|---|---|---|
| 板载 LED | GPIO2 | 输出 | `LED_BUILTIN` | 板载蓝色 LED，**高电平点亮**；仅作自检，不接外部负载 |
| BH1750 SDA | GPIO21 | 双向 | 正式固件硬编码 `Wire.begin(21, 22)`；验证固件里是 `I2C_SDA` | ESP32 默认 I2C 数据线 |
| BH1750 SCL | GPIO22 | 输出 | 同上（验证固件 `I2C_SCL`） | ESP32 默认 I2C 时钟线 |
| 灯带 PWM | GPIO25 | 输出(PWM) | `LED_PWM_PIN`（正式固件）/ `PWM_PIN`（`light_pwm_test`） | 经 MOS 模块信号端（`IN+`），**不直接接灯带** |
| RGB 绿（**正常**） | GPIO26 | 输出 | `GREEN_LED_PIN` | 共阴 RGB 模块 G 脚；高电平点亮 = 检测正常 |
| RGB 红（**异常**） | GPIO27 | 输出 | `RED_LED_PIN` | 共阴 RGB 模块 R 脚；高电平点亮 = 检测异常 |
| RGB 公共端 | GND | — | — | 共阴模块的 `-`/GND 脚；**B 脚不接**（本方案只用红绿两态） |
| 有源蜂鸣器 | GPIO32 | 输出 | `BUZZER_PIN` | 高电平触发；异常时短鸣 |
| 串口 TX | GPIO1 | 输出 | — | 接 CP2102，**别占用** |
| 串口 RX | GPIO3 | 输入 | — | 接 CP2102，**别占用** |

> GPIO26 = 绿 = 正常，GPIO27 = 红 = 异常，这个对应关系**不要接反**，
> 否则演示时"检出缺陷亮绿灯"，逻辑直接反了。

## 二、禁止使用的引脚（踩了就出怪问题）

| GPIO | 为什么不能用 |
|---|---|
| GPIO6 ~ GPIO11 | 连接板载 SPI Flash，占用后**直接无法启动** |
| GPIO34 ~ GPIO39 | **只能输入**，没有输出能力，接灯/PWM 无效（可作 ADC 输入） |
| GPIO0 | 就是 **BOOT 按键**，外接负载会导致无法进入下载模式 |
| GPIO2 | 板载 LED + 启动模式绑带脚，外接负载可能影响启动（本项目仅用作板载灯） |
| GPIO12 / GPIO15 | 启动绑带脚（Flash 电压/启动日志），上电时电平不对会启动失败 |
| GPIO1 / GPIO3 | USB 串口 TX/RX，占用后无法看日志、无法烧录 |
| GPIO20 / GPIO24 | 部分模块未引出；GPIO20 一般不可用 |

## 三、电源引脚

| 引脚 | 说明 |
|---|---|
| 3V3 | 给 BH1750、蜂鸣器模块供电。**总输出能力有限（约 600mA 上限，受 USB 供电制约）**，不要挂大负载 |
| 5V / VIN | 接 USB 5V。灯带**不要**从这里取大电流（1A 以上会拉低电压导致 ESP32 复位） |
| GND | 与外部灯带电源**必须共地**：本方案 MOS 模块控制端为 `IN+` / `IN-`，`IN-` 就是控制地，必须与 ESP32 的 GND 连通。（换用带光耦隔离输入的模块时，控制地接法只按该模块资料决定，不要自行把隔离输入地与负载地短接。） |

## 四、本机环境（验证通过的环境，照抄即可）

| 项目 | 值 |
|---|---|
| 电脑 | Windows，Arduino IDE 2.x（`D:\arduino IDE\Arduino IDE.exe`） |
| 开发板支持包 | `esp32:esp32@3.3.12` |
| 板型（FQBN） | `esp32:esp32:esp32`（即 IDE 里的 **ESP32 Dev Module**） |
| 串口 | **COM5**（Silicon Labs CP210x USB to UART Bridge，VID_10C4 / PID_EA60） |
| 串口速率 | 115200 |
| 下载模式 | 本板**无自动下载电路**，烧录时必须手动按 BOOT（见 README） |

## 五、PWM 参数对照（别搞混）

| 固件 | 频率 | 分辨率 | 启动默认亮度 |
|---|---|---|---|
| `light_pwm_test`（本验证库） | **8 kHz** | 8 位（duty 0~255） | 0% |
| `lightguard_esp32.ino`（正式固件） | **8 kHz** | 8 位 | **45%** ← 复位后会自己亮到 45% |

> PWM 频率 2026-10-07 由 1kHz 提到 8kHz。**已验证**：1kHz 下相机画面出现 PWM 频闪横向条纹
> （三帧逐行灰度波动标准差 8.85 / 8.78 / 8.80）。**待验证**：改成 8kHz 后尚未重新采集逐帧数据，
> "条纹基本消失"只是按单行曝光跨越多个 PWM 周期做的推断。
> 若换用额定频率 ≤1kHz 的模块（如 YYMOS-1），必须改回 1kHz。

> ⚠️ 因为正式固件复位后默认 45%，**每次 ESP32 重启、拔插 USB、COM 口重连之前，先断开灯带 5V 电源**，
> 避免无人看管时灯带突然满负荷点亮（发热/晃眼/耗电）。
