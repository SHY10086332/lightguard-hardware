# 安装现场核对单

按顺序完成。每一项通过后再进入下一项。只要遇到端子名称、电压、极性或模块型号不确定，就停在当前步骤并拍照确认。

## A. 开始前

- [ ] 5V适配器已拔出，ESP32 USB线未接电脑。
- [ ] 桌面干燥、整洁，纸箱、控制板、电源和灯带暂时分开放置。
- [ ] 没有拆开适配器外壳，也没有接触220V市电。
- [ ] 已准备直尺、胶带、硬纸板、剪刀和螺丝刀。

## B. 纸箱和样品定位

- [ ] 已量纸箱内尺寸，并记录实测的宽、深、高。目标参考值为内宽365mm、内深490mm、内高315mm。
- [ ] A4纸平放在箱底，297mm边沿箱宽方向，210mm边沿箱深方向。
- [ ] A4纸四角已用胶带做定位线。
- [ ] 60mm × 40mm 标签位于A4纸的定位标记内（见 `05_数据集与标签设计/`）。
- [ ] 纸张没有卷边，标签不会遮挡或超出相机预期画面。

## C. 摄像头试拍

- [ ] USB摄像头已直接接电脑，并在Windows“相机”应用中确认有画面。
- [ ] “相机”应用已关闭，项目网页已获得摄像头权限。
- [ ] 已确认项目预览使用的是外接USB摄像头，不是笔记本内置摄像头。
- [ ] 摄像头已用硬纸板横梁临时固定，镜头垂直朝下且不会掉落。
- [ ] 已实测镜头最前端到A4纸面的距离；约305～315mm只是起始试拍范围，不是必须值。
- [ ] 标签完整、居中、文字可辨认，边缘没有被裁掉。
- [ ] 已用一张细缺陷样纸确认细线或小缺陷也能看见。
- [ ] 此时尚未在纸箱上开镜头孔，也没有把USB插头穿过纸箱。

## D. ESP32和BH1750

- [ ] ESP32固件上传成功，Arduino串口监视器已关闭。
- [ ] 修改接线前，ESP32 USB线已拔出。
- [ ] BH1750 VCC接ESP32 3V3。
- [ ] BH1750 GND接ESP32 GND。
- [ ] BH1750 SDA接GPIO21。
- [ ] BH1750 SCL接GPIO22。
- [ ] VCC没有接到5V/VIN，四根线没有裸铜相碰。
- [ ] 网页已选择“ESP32串口实物”和正确COM口，状态显示“ESP32实物”。
- [ ] 遮住再放开BH1750感光面时，lux读数会明显变化。

## E. MOS和灯带：未确认前停在这里

- [ ] 适配器铭牌确认是5V直流。
- [ ] 灯带确认是5V单色、两根电源线，并知道总功率或总电流。
- [ ] 已确认MOS模块准确型号。
- [ ] 已拍清MOS模块正面、背面、全部端子丝印和商品接线图。
- [ ] 已确认模块支持3.3V PWM输入、5V负载，额定电流有余量。
- [ ] 已确认PWM有效电平、是否隔离、控制地接法和负载端接法。
- [ ] 已确认DC5521母座线与适配器插头尺寸和极性匹配。
- [ ] **以上任一项未确认：不插5V适配器，不尝试猜端子。**

## F. 第一次桌面点灯

- [ ] 接线前，ESP32 USB线和5V适配器都已拔出。
- [ ] 灯带电源线使用合适线径，未经过面包板或细杜邦线。
- [ ] GPIO25只接到模块说明标明的PWM/SIG/TRIG输入。
- [ ] 控制地已按该模块说明确认：本方案 MOS 模块控制端为 `IN+`/`IN-`，`IN-` 即控制地，必须与 ESP32 的 GND 连通（不共地会导致灯常亮/乱闪）。换用光耦隔离输入的模块时，按该模块资料决定控制地接法，不要自行把隔离输入地与负载地短接。
- [ ] 端子拧紧，无散出的铜丝，正负极性已复核。
- [ ] 先只接ESP32 USB，网页确认“ESP32实物”和正确COM口。
- [ ] 灯带5V适配器仍拔着，网页亮度已设为0%，并确认页面显示0%。
- [ ] 插入5V适配器后，只短时观察灯带。
- [ ] 网页调节0%、低亮度和较高亮度时，灯带依次熄灭、变暗、变亮。
- [ ] 出现发热、异味、冒烟、异常闪烁或常亮失控时，已立即拔掉5V适配器。

## G. 灯带入箱试摆和测光

- [ ] 重新摆放前，5V适配器和ESP32 USB都已拔出。
- [ ] 灯带沿侧壁和后侧临时摆放，灯珠没有直射镜头。
- [ ] 灯带用胶带临时固定，尚未剪短或撕掉全部背胶。
- [ ] 合盖检查过，没有明显白色亮斑、强反光或标签阴影。
- [ ] BH1750先在标签中心、左前、右前、左后、右后各测过一次lux，并记录结果。
- [ ] BH1750最终固定在标签旁、感光面朝上、不被遮挡的位置。
- [ ] 若使用描图纸/烘焙纸柔光，纸张与灯带留有间距，没有贴住发热灯带。
- [ ] 首次连续点亮10分钟时有人看管，纸箱、胶带、线材和MOS无明显发热或气味。

## H. 最终固定相机和封箱

- [ ] 灯带位置确定后，相机画面重新确认标签完整、居中、清晰。
- [ ] 已选定一种相机固定方式：箱盖外侧小镜头孔，或箱内硬纸板横梁；没有混用。
- [ ] 只有需要时才开镜头小孔，孔边已用硬纸板加固。
- [ ] USB线没有让插头穿过纸箱；走线孔按线径开小孔并封住漏光缝。
- [ ] 合盖后箱盖不碰镜头、不压线、不压灯带。
- [ ] ESP32、面包板、MOS模块和适配器均放在纸箱外。

## I. 最终验收和记录

- [ ] 连续预览20次，画面不黑屏，标签位置稳定。
- [ ] A4纸取出再放回定位线5次，标签在画面中的位置基本不变。
- [ ] BH1750遮挡/放开读数变化正常。
- [ ] 灯带0%、低亮度、高亮度控制正常。
- [ ] 已拍照记录：纸箱内部布局、相机位置、灯带位置、BH1750位置、ESP32和MOS接线。
- [ ] 正式采集训练图片前，已确认样品每次放回同一定位区域。

## 遇到异常时的统一动作

1. 先拔掉5V灯带适配器。
2. 如果要改线，再拔掉ESP32 USB线。
3. 不带电拔插端子，不在不确定时猜MOS端子。
4. 拍清楚模块正反面、端子文字和当前接线，再继续排查。
