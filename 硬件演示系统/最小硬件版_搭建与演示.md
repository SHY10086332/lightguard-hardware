# 光稳智检盒：最小硬件版搭建与演示

本文件只负责到货后的结构、接线、烧录和演示。全过程顺序见 `00_从采购到参赛_执行总表.md`，下单型号和搜索词见 `最低成本采购清单_标签质检纸箱版.md`。

**首次安装请优先照 `硬件安装一步一步.md` 操作。**本页保留较早版本的概要，其中摄像头距离和MOS负载端示意已过时；不要据此开孔或猜接线。

## 1. 作品定位

作品名称建议：**光稳智检盒——低成本自适应光照AI质检终端**。

本版本只实现一个清晰、可验证的闭环：

```text
BH1750测量照度
    ↓
ESP32自动调节白光灯带
    ↓
USB摄像头采集产品图像
    ↓
电脑运行PatchCore异常检测
    ↓
网页显示热力图和检测报告
    ↓
ESP32控制RGB灯红/绿通道和蜂鸣器反馈
```

不加入机械臂、麦轮底盘、自动转盘、显示屏、树莓派和3D打印外壳。检测对象固定为普通A4纸上打印的 60mm × 40mm 工业标签（见 `05_数据集与标签设计/labels/`），正式演示使用自训练的 `printed_label` 模型。

## 2. 硬件组成

完整采购表、可复制搜索词、预算和避坑条件统一放在 `最低成本采购清单_标签质检纸箱版.md`，本页不再维护另一份重复清单。

核心系统由以下部分组成：

| 部分 | 作用 | 统一规格 |
|---|---|---|
| ESP32-WROOM-32开发板 | 主控制器和USB串口通信 | Type-C、CH340/CP2102、已焊排针 |
| GY-302 BH1750 | 测量样品照度 | 已焊排针、3.3V、I2C |
| UVC USB摄像头 | 采集标签图像 | 低成本首选`720P 55度3.8MM无畸变带外壳`；确认UVC、1280×720 MJPEG 30fps、可调焦和USB线 |
| COB灯带 | 稳定照明 | 5V、8mm宽、300灯/米、1米高亮款、中性光、单色两线，优先Ra≥90 |
| XY-MOS或YYMOS-1 PWM模块 | 调节灯带亮度 | 必须支持3.3V PWM和5V负载；YYMOS-1负载总功率建议≤10W |
| 灯带电源 | 独立供电 | 5V 4A适配器 + DC5521母座带红黑线（5A款） |
| 面包板和杜邦线 | 无焊接连接 | MB-102 830孔（165×55×10mm）；公对公/公对母/母对母三种线 |
| DC5521母座带线 | 适配器到PWM模块 | 5.5×2.1mm、红黑线约20～30cm、额定≥3A，优先5A款 |
| 0.5mm²红黑多股软线 | 灯带延长线 | 灯带自带线够长时不用买；不能用细杜邦线代替灯带电源线 |
| 共阴RGB灯模块和蜂鸣器 | 检测结果反馈 | RGB灯选共阴、四针、自带限流电阻；蜂鸣器选3.3～5V高电平触发有源模块 |
| 定制五层瓦楞纸箱和描图纸 | 暗箱与柔光 | 纸箱按内尺寸深490×宽365×高315mm使用；描图纸可等试灯后再决定 |

核心硬件预算约 **112～243元**；RGB灯、蜂鸣器和耗材可稍后补充。价格以下单当天为准。

## 3. 纸箱与样品尺寸

| 项目 | 建议值 |
|---|---|
| 纸箱内部尺寸 | 深490mm × 宽365mm × 高315mm |
| 标签外框 | 60mm × 40mm，每张A4排18个（见 `05_数据集与标签设计/`） |
| 摄像头画面 | 完整覆盖单张 60mm × 40mm 标签即可，不要求覆盖整张A4 |
| 镜头到纸面距离 | 箱内高约315mm时，先按镜头最前端距A4纸面约305～315mm临时试拍；以实际清晰度和标签画面为准，不预设安装孔 |
| 灯带 | 购买1米，优先沿左右两侧上部和后侧上部做U形布置；以照度均匀性决定是否裁剪 |

第一版不需要模块精确孔位和外壳尺寸。相机、传感器和灯带使用胶带或扎带固定，普通直尺测到5mm精度即可。

这个箱体的宽365mm、高315mm，底面足以直接平放A4纸（210mm × 297mm），不需要在正面开进料口。将A4纸横向放在箱底中央：纸张297mm方向沿箱体宽度365mm方向，210mm方向沿箱体深度490mm方向。先用纸板横梁试拍，待灯带位置、合盖画面和相机高度都确认后，再决定是否开刚好够镜头通过的小孔；走线优先从箱盖边缘临时引出，确有需要时按线缆粗细开小孔，不开大孔。

## 4. 接线表

| 设备引脚 | 接到 | 作用 |
|---|---|---|
| BH1750 VCC | ESP32 3V3 | 传感器供电 |
| BH1750 GND | ESP32 GND | 共地 |
| BH1750 SDA | ESP32 GPIO21 | I2C数据 |
| BH1750 SCL | ESP32 GPIO22 | I2C时钟 |
| MOS模块PWM/SIG/TRIG输入 | ESP32 GPIO25 | 仅在该模块资料确认它是兼容3.3V的PWM逻辑输入后连接 |
| MOS模块控制地 | ESP32 GND | 按该模块接线图决定；隔离输入不能自行与负载地短接 |
| 共阴RGB模块 G | ESP32 GPIO26 | 正常时点亮绿色通道 |
| 共阴RGB模块 R | ESP32 GPIO27 | 异常时点亮红色通道 |
| 共阴RGB模块 －/GND | ESP32 GND | 共阴公共端 |
| 共阴RGB模块 B | 不连接 | 蓝色通道第一版不用 |
| 蜂鸣器模块 VCC | ESP32 3V3 | 蜂鸣器模块供电 |
| 蜂鸣器模块 GND | ESP32 GND | 共地 |
| 蜂鸣器模块 IN/S | ESP32 GPIO32 | 异常时短鸣 |

灯带由独立5V电源供电，不能接ESP32的3V3供电脚。MOS端子排列、负载接法、PWM有效电平和是否共地都依具体模块而定；必须按准确型号的接线图接线，资料不完整时不连接5V电源。全系统只使用5V/3.3V低压模块，不自行拆接220V市电。

当前固件预期PWM占空比越高时灯带越亮，但MOS模块必须支持ESP32 3.3V PWM、匹配5V负载和 **8kHz** PWM（本项目实测用 8kHz：1kHz 会让相机画面出现频闪条纹），并通过桌面短测验证。固件启动默认亮度现为 **0%**（2026-10-09 烧录验证，复位不会自己亮）；首次测试时仍建议先保持灯带5V电源拔掉，在网页选择“ESP32串口实物”、选择正确COM口并连接，确认状态标记变成“ESP32实物”后，再把亮度设为0%。每次ESP32重启或COM口重连前都先断开灯带5V电源。

## 5. 没有硬件时的运行方式

1. 双击 `start.bat`，访问 `http://localhost:5051`。
2. 页面“光照硬件终端”默认选择“模拟硬件”。
3. 点击“自动稳光”，观察照度和灯光亮度变化。
4. 加载产品类别后，上传样例图像进行检测。
5. 检测完成后，页面反馈状态会变为“正常 / 绿灯”或“异常 / 红灯”。

模拟模式只用于开发和讲解流程，不能替代最终的实物测试证据。

## 6. 硬件到手后的接入方式

1. 打开箱盖，把A4纸横向放在箱底中央，297mm方向沿365mm宽度方向，210mm方向沿490mm深度方向；用纸板横梁临时固定摄像头并垂直向下拍标签，镜头最前端距纸面先从约305～315mm试起，再按实时画面调整。
2. 灯带布置在纸箱上部左右两侧和后侧，灯珠朝侧壁或斜向下，不能直接进入摄像头画面；描图纸与灯带之间留空气间隙。
3. BH1750感光面朝上，放在样品平面附近且不被遮挡。
4. 先只按本文件BH1750表格接线；MOS端子不能按通用表格猜接，先确认实物型号及其接线图。
5. 使用Arduino IDE烧录 `firmware/lightguard_esp32/lightguard_esp32.ino`。
6. 单独验证ESP32、BH1750和串口返回正常。
7. 确认MOS模块额定值、端子图、3.3V PWM兼容性、隔离/共地方式和灯带功率后，再按《硬件安装一步一步.md》连接；不确定MOS端子时，不进行灯带上电测试。
8. 灯带5V适配器仍拔着，网页选择“ESP32串口实物”，选择对应COM口并连接，确认已经连接到实物后再继续。
9. 在实物模式把亮度设为0%并确认；固件复位默认值现为 **0%**（2026-10-09 验证），重启/拔插 USB/重连 COM 口都不再点亮灯带。之后按详细安装手册短时点灯。
10. 将样品放入暗箱，设定目标照度900 lux，执行自动稳光。**亮度对应关系需按最终 BH1750 位置标定一次**（不同摆放位置的 lx/% 斜率不同，实测出现过 39 与 28.5 两种）。
11. 打开USB摄像头，点击“稳光拍照并检测”。
12. 连续点亮10分钟，确认灯带、导线和纸箱没有明显发热；设备无人看管时断开灯带电源。

## 7. 最小验收标准

实物作品至少通过以下检查后再录制比赛视频：

| 验收项目 | 合格条件 |
|---|---|
| 串口连接 | 连续启动10次，无无法连接故障 |
| 照度读取 | BH1750数据随遮挡和灯光变化而变化 |
| 自动稳光 | 3次测试均能进入目标照度 ±30 lux（900 lx）；测试前先记录「达到 900 lx 所需亮度 %」，并把 BH1750 固定在最终箱内标签位 |
| 摄像头 | 连续采图20次，无黑屏、严重虚焦 |
| AI检测 | 正常样品与人工制造缺陷均能输出结果和热力图 |
| 状态反馈 | 正常亮绿灯；异常亮红灯并短鸣 |
| 报告导出 | CSV包含结果、分数、阈值、照度和灯光亮度 |
| 稳定性 | 连续运行30分钟，无程序崩溃和灯带异常发热 |

## 8. 比赛演示脚本（约2分钟核心段落）

1. 展示低成本暗箱、摄像头、ESP32、照度传感器和灯带。
2. 用手遮挡光线，页面照度下降；点击自动稳光，灯带自动补偿。
3. 加载自己训练的 `printed_label` 类别，放入正常样品，点击“稳光拍照并检测”，展示绿灯、正常判定和热力图。
4. 换成带划痕或贴纸的异常样品，再次检测，展示红灯、蜂鸣器和异常区域。
5. 导出CSV报告，说明每次检测都保留时间、分数、照度和灯光亮度。
6. 最后说明本作品在普通电脑上离线运行，硬件成本低，适合小微生产线和教学实训。

## 9. 数据与表述边界

- 现有MVTec权重适合演示算法能力，不等同于真实产线泛化能力。
- 正式参赛固定使用A4打印工业标签，采集自己的正常/缺陷样本并训练 `printed_label.pth`。
- 至少对比“固定灯光”和“自动稳光”两组，报告误报率、漏报率、F1、检测时间和照度波动。
- 不把模拟模式结果写成实物测量结果；没有完成的稳定性测试应明确标为待验证。
