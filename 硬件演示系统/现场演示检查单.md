# 现场演示检查单（一页版）

> 打印这一页，演示前逐项打勾。左边是动作，右边是"看到什么才算对"。

---

## 一、接线与上电（**先断电再接线**）

| # | 动作 | 看到什么才算对 |
|---|---|---|
| 1 | 灯带 5V 电源**先不插** | —— |
| 2 | BH1750：`SCL→GPIO22`、`SDA→GPIO21`、`VCC→3V3`、`GND→GND`、`ADDR→GND` | 四根线不松动；**VCC 绝不能接 5V** |
| 3 | MOS 模块：`GPIO25→IN+`、`GND→IN-`、`OUT+→灯带红`、`OUT-→灯带黑` | 灯带黑线也回到模块，不是回 ESP32 |
| 4 | 指示灯：`GPIO26→绿`、`GPIO27→红`、`GPIO32→蜂鸣器` | 红绿别接反 |
| 5 | ESP32 USB 插到电脑 | 设备管理器出现 **CP210x / COM5** |
| 6 | 最后再插灯带 5V 适配器 | 灯带**不该亮**（正式固件默认亮度 0；老固件会亮到 45%） |

## 二、软件启动（顺序别乱）

| # | 动作 | 看到什么才算对 |
|---|---|---|
| 7 | 双击 `硬件演示系统\演示台\0_启动演示台.bat` | 黑窗口出现"硬件：已连接 COM5（LIGHTGUARD_ESP32）" |
| 8 | 浏览器开 **http://127.0.0.1:8790/** | 页面能打开（用 127.0.0.1，别用局域网 IP） |
| 9 | 点「打开摄像头」→ 选 **USB Camera** | 画面出现，不是笔记本自带摄像头 |
| 10 | 点「关灯」 | 灯带灭，页面照度掉到接近 0 |

> ⚠️ **镜头里绝不能出现证件、成绩单、家庭情况表、聊天窗口等个人内容**。
> 演示前把桌面清干净、把纸质材料收走（这条写进了《演示视频拍摄脚本》，现场同样适用）。

## 三、演示四步（照这个顺序走）

| # | 动作 | 说明 |
|---|---|---|
| 11 | 放一张**合格品**标签 → 点「设为参考图」 | 提示"参考图已设置（709×472）" |
| 12 | 目标填 `300`、容差填 `20` → 点「开始稳光」 | 曲线上升并收敛，右侧显示"稳光：已达标"（本机约 9 秒） |
| 13 | 换上**待检**标签 → 按 **Enter** | 页面出现 ✅正常 / ⛔异常，**同时硬件亮绿/红灯**（异常还有短鸣） |
| 14 | 点「导出/记录」看 `演示记录.csv` | 每行都有：时间、图片、照度、亮度、判定、差异% |

**可选的加分演示**：把亮度手动改掉（比如 `50`）再拍同一张缺陷品 → 差异占比变化，
说明"光照不稳会误判"——这正是本系统要解决的问题。

## 四、安全红线（每次都要做到）

1. **不许留下亮着的灯带**：结束前点「关灯」，或双击 `关灯_应急.bat`，或拔掉 5V；
2. 拔插 USB / 按复位前**先关灯**（老固件复位会回到 45%）；
3. 带电不要插拔 I2C 与灯带线；
4. 串口同一时刻只能一个程序用：演示台开着时，别同时开 Arduino 串口监视器 / 采集台。

## 五、故障速查

| 现象 | 处理 |
|---|---|
| 演示台说"未连接硬件" | 串口被占用 → 关掉串口监视器/采集台；或 USB 松了 |
| 页面打不开摄像头 | 必须用 `http://127.0.0.1:8790`；再检查浏览器权限、别被微信/会议软件占用 |
| 「开始稳光」报错 | 已有一轮在跑 → 先点「停止」 |
| 目标照度达不到 | 目标定太高（本机 100% ≈ 966 lx）；或传感器被挡 |
| 合格品被判异常 | 阈值调松一点（0.4~0.6）；或机位动了 → 重新「设为参考图」 |
| 灯一直亮着关不掉 | 双击 `关灯_应急.bat`；仍不行就直接拔灯带 5V |
